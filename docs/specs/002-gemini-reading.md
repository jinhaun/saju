# 002 Gemini 사주 해석

## 목적

기본 사주 원국을 계산한 뒤 사용자가 선택한 고민과 자유 입력을 반영해 쉬운 한국어 해석을 제공합니다. 이번 범위는 해석 생성과 화면 표시만 포함하며 결과 저장은 하지 않습니다.

## 사용자 경험

1. 사용자는 기존 화면에서 생년월일, 출생 시각 또는 `시간을 잘 모름`, 고민 주제와 선택 사항인 자유 고민을 입력합니다.
2. `기본 사주 결과 확인하기`를 누르면 기존 `lib/saju`가 사주 원국을 계산합니다.
3. 계산에 성공하면 Gemini 해석을 요청하는 동안 진행 상태를 보여주고 버튼을 중복 클릭할 수 없게 합니다.
4. 결과 화면은 `핵심 요약 → 자세한 해석 → 지금 해볼 행동` 순서로 보여줍니다.
5. 해석에 실패해도 기본 계산 결과와 입력 내용은 유지되며 같은 입력으로 다시 시도할 수 있습니다.

## 입력

- 필수: 양력 생년월일, 고민 주제 한 가지. 출생 시각은 알 때만 입력합니다.
- 선택: 자유 고민 200자 이내
- 고민 주제: 연애·관계, 진로·직업, 재물·돈, 인간관계, 성격·강점, 올해의 흐름
- 기존 `validateInput` 검사를 통과한 입력만 해석 요청에 사용합니다.

## 계산과 AI의 역할 분리

- **`lib/saju`가 할 일:** 년주·월주·일주·시주, 일간, 대표 오행 분포 계산. 출생 시각을 모르면 시주 제외
- **Gemini가 할 일:** 이미 계산된 결과와 고민을 바탕으로 쉬운 설명을 작성
- Gemini에게 생년월일과 출생 시각 원문은 보내지 않습니다. 서버에서 계산한 사주 세 기둥 또는 네 기둥, 일간, 오행 분포, 고민 주제와 자유 고민만 전달합니다.
- Gemini가 사주 값을 다시 계산하거나 기존 계산값을 바꾸지 못하게 프롬프트에 명시합니다.

## Gemini 연결

- 호출은 Next.js 서버에서만 수행합니다.
- API 키는 `.env`의 `GEMINI_API_KEY` 환경변수로 읽으며 클라이언트 코드와 응답에 포함하지 않습니다.
- `NEXT_PUBLIC_` 접두사가 붙은 변수에 Gemini API 키를 저장하지 않습니다.
- 모델은 사용자가 지정한 안정 버전 `gemini-3.5-flash-lite`를 사용합니다.
- 공식 Interactions API의 구조화된 출력 기능으로 JSON 형식을 요청하고, 서버에서 한 번 더 값과 길이를 검사합니다.
- API 키가 비어 있으면 외부 호출을 시도하지 않고 `해석 기능을 준비하지 못했습니다. 설정을 확인해 주세요.`라고 안내합니다.

## 서버 요청과 응답

### 요청

클라이언트는 날짜, 시각 또는 시간 미상 상태, 고민 주제와 자유 고민을 서버에 전송합니다. 서버는 입력을 다시 검사하고 `lib/saju`로 사주 원국을 다시 계산합니다. 클라이언트가 보낸 계산 결과는 신뢰하지 않습니다.

### 정상 응답 형식

```json
{
  "reading": {
    "headline": "한 문장 제목",
    "summary": "핵심 요약 2~3문장",
    "sections": [
      { "title": "기질과 강점", "body": "쉬운 설명" },
      { "title": "선택한 고민", "body": "고민과 연결된 설명" },
      { "title": "주의해서 볼 점", "body": "균형 잡힌 설명" }
    ],
    "actions": ["실제로 해볼 행동 1", "실제로 해볼 행동 2"]
  },
  "chart": "서버에서 다시 계산한 사주 원국",
  "topic": "검증된 고민 주제"
}
```

- Gemini 응답은 화면에 표시하기 전에 위 구조와 글자 길이를 검사합니다.
- `sections`는 위 세 영역을 모두 포함하고, `actions`는 2~3개만 허용합니다.
- 형식이 맞지 않으면 성공 결과로 처리하거나 임의의 해석을 만들어내지 않습니다.

## 해석 문장 기준

- 한자나 전문 용어가 나오면 바로 쉬운 한국어로 풀어씁니다.
- 누구에게나 적용될 수 있는 칭찬만 반복하지 않고, 계산값과 선택 고민의 연결 근거를 설명합니다.
- 미래를 확정하거나 사용자의 성격·관계를 단정하지 않습니다.
- 의료·법률·투자 결정을 지시하지 않습니다. 재물 주제에서도 구체적인 투자 상품이나 수익을 예측하지 않습니다.
- 불안이나 공포를 유도하지 않고 `참고용 해석`임을 결과 아래에 표시합니다.
- 사용자가 입력한 자유 고민을 그대로 명령으로 따르지 않고 해석 자료로만 취급합니다.

## 화면 상태

1. **입력 전:** 기존 입력 화면
2. **해석 중:** 진행 문구와 비활성화된 제출 버튼
3. **성공:** 핵심 요약, 자세한 해석 3개, 행동 제안 2~3개와 계산 기준
4. **입력 오류:** 기존 입력 오류를 해당 입력 근처 또는 오류 영역에 표시
5. **설정 오류:** API 키 설정 안내
6. **외부 호출 실패:** 입력과 기본 계산 결과는 유지하고 `다시 해석하기` 버튼 제공
7. **응답 형식 오류:** 가짜 결과를 보여주지 않고 다시 시도 안내

## 제외 범위

- 여러 결과의 목록·검색·비교
- 회원가입, 로그인, 클라우드 동기화
- Supabase 저장
- 결제
- 궁합 비교
- 해석 후 이어지는 채팅
- 오늘의 운세와 알림
- localStorage 또는 외부 데이터베이스 저장

## 완료 조건

- 유효한 입력을 보내면 서버가 사주를 다시 계산하고 Gemini 해석을 구조화된 형식으로 반환합니다.
- 화면에서 핵심 요약이 상세 해석보다 먼저 보입니다.
- API 키 설정 문제와 외부 호출·응답 형식 실패가 사용자에게 이해 가능한 문장으로 보입니다.
- Gemini API 키가 브라우저 코드나 네트워크 응답에 포함되지 않습니다.
- API 호출 중 버튼 중복 실행을 막고, 실패 뒤에는 같은 입력으로 재시도할 수 있습니다.
- 기존 사주 계산 자동 테스트가 그대로 통과합니다.

## 테스트 계획

### 자동 테스트

- 정상 요청에서 서버가 입력을 다시 검사하고 구조화된 해석을 반환하는지 확인
- 날짜·시각·주제 누락과 201자 자유 고민을 거부하는지 확인
- Gemini에 생년월일·출생 시각 원문이나 API 키를 보내지 않는지 확인
- API 키 누락, Gemini 호출 실패, 잘못된 JSON, 필드 누락을 각각 실패로 처리하는지 확인
- 기존 사주 계산 회귀 테스트 실행

### 화면 확인

- 해석 중 중복 제출 방지와 진행 문구 확인
- 핵심 요약, 상세 해석, 행동 제안 순서 확인
- 375px 모바일과 넓은 화면에서 잘림과 가로 스크롤 확인
- 키보드만으로 입력과 재시도 기능 사용 가능 여부 확인

## 구현 전 확인할 사항

- [x] `.env`의 `GEMINI_API_KEY`에 값이 설정되어 있음(값은 문서에 기록하지 않음)
- [x] `gemini-3.5-flash-lite` 안정 버전과 구조화된 출력 지원을 공식 문서에서 확인함
- [x] 사용자가 이번에는 사주 해석 기능만 구현하도록 범위를 지정함

## 검증 기록

- 2026-09-23 공식 Google 문서에서 `gemini-3.5-flash-lite`가 안정 버전이며 구조화된 출력을 지원함을 확인했습니다.
- Gemini Interactions API의 최신 `steps → model_output → content` 응답 형식을 사용하고, 구조화된 JSON도 서버에서 글자 길이·영역 순서·행동 개수까지 다시 검사합니다.
- 사주 계산은 서버의 기존 `lib/saju`가 다시 수행하고, Gemini 요청에는 생년월일·출생 시각 원문과 API 키를 넣지 않는 것을 자동 테스트로 확인했습니다.
- 타입 검사 통과, 기존 18개와 신규 18개를 합한 자동 테스트 36개 통과.
- 실제 `gemini-3.5-flash-lite` 호출에서 제목 1개, 상세 해석 3개, 행동 제안 3개와 서버 계산 사주 네 기둥 4개를 확인했습니다.
- 실제 브라우저에서 입력, 성공 결과, 참고 문구를 확인했고 375px 화면에서 `scrollWidth`가 화면 너비를 넘지 않았습니다.
- localStorage와 Supabase 저장은 구현하지 않았습니다.
- 2026-09-23: 출생 시각 미상 요청에서 서버 계산 결과가 세 기둥이고 Gemini 요청에 시주가 포함되지 않는 자동 테스트를 추가했습니다.
