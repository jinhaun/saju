# 007 비슷한 사주 찾기

## 목적

사용자가 자신의 생년월일과 출생 시각을 입력하면, 1900년부터 2026년까지의 달력에서 일주가 같고 나머지 기둥과 오행 구성이 가까운 날짜 5개를 보여줍니다. 실제 서비스 이용자나 개인정보를 검색하지 않습니다.

## 사용자 경험

1. 사용자는 양력 생년월일과 출생 시각을 입력합니다.
2. 출생 시각을 모르면 `시간을 잘 모름`을 선택할 수 있습니다.
3. `비슷한 사주 찾기`를 누르면 계산 중 상태를 보여주고 중복 실행을 막습니다.
4. 결과는 닮은 정도가 높은 순서로 최대 5개를 보여줍니다.
5. 각 결과에는 날짜, 같은 출생 시각 또는 시간 미상 표시, 닮은 정도, 같은 기둥, 오행 유사도와 세 기둥 또는 네 기둥을 표시합니다.

## 비교 대상

- 지원 범위는 `1900-01-01`부터 `2026-12-31`까지입니다.
- 입력 날짜와 일주가 같은 날짜를 후보로 삼습니다. 같은 시각 기준의 일주는 60일마다 반복되므로 입력 날짜에서 앞뒤로 60일씩 이동해 후보를 만듭니다.
- 입력한 날짜 자체는 제외합니다.
- 모든 기둥이 완전히 같은 결과는 제외해 `비슷하지만 완전히 같지는 않은 사주`만 보여줍니다.
- 출생 시각을 아는 경우 후보도 같은 시각으로 계산합니다.
- 출생 시각을 모르면 정오 기준으로 년주·월주·일주만 계산하고 시주는 비교하지 않습니다.

## 점수 기준

- 같은 기둥 하나마다 15점
- 같은 일간 15점
- 같은 일지 10점
- 오행 분포 유사도
  - 시각을 알면 최대 15점
  - 시각을 모르면 최대 30점
- 최고점은 100점이며, 완전히 같은 사주는 결과에서 제외합니다.
- 점수는 관계나 성격을 판단하는 값이 아니라 계산 구조가 얼마나 닮았는지 설명하는 참고값입니다.

## 서버 API

### `POST /api/similar-saju`

- 요청: `date`, `time`, `unknownTime`
- 서버는 기존 `validateInput`과 `calculate`를 사용해 입력과 후보를 다시 계산합니다.
- 클라이언트가 보낸 점수나 사주 계산값은 사용하지 않습니다.
- Gemini와 Supabase를 호출하지 않습니다.
- 정상 응답은 기준 사주 요약, 상위 후보 5개와 비교 기준 문구를 반환합니다.
- 잘못된 입력은 400, 예상하지 못한 계산 실패는 개인정보를 포함하지 않는 500 안내를 반환합니다.

## 화면과 접근성

- 기존 조선 고서 디자인을 유지합니다.
- 입력 항목은 항상 보이는 레이블을 사용합니다.
- 시간 미상 버튼은 눌림 상태를 보조기기에 전달하고, 선택 시 시간 입력을 비활성화합니다.
- 계산 중 상태와 오류는 화면 읽기 프로그램에도 전달합니다.
- 점수만 색으로 구분하지 않고 숫자와 설명을 함께 표시합니다.
- 모바일에서는 결과 카드가 한 열로 쌓이고 가로 스크롤이 생기지 않아야 합니다.

## 제외 범위

- 실제 가입자 검색과 이용자 간 연결
- 연예인·유명인 데이터베이스
- 완전히 같은 사주 찾기
- Gemini 해석 생성
- 결과 저장과 공유

## 완료 조건

- 정상 입력에서 서로 다른 날짜의 유사 결과를 최대 5개 반환합니다.
- 결과가 점수 내림차순이며 입력 날짜와 완전히 같은 사주가 포함되지 않습니다.
- 시간 미상 입력은 세 기둥만 비교하고 결과에도 시주가 없습니다.
- 날짜 범위와 잘못된 시간 입력을 기존 규칙대로 거부합니다.
- 기존 사주 해석, 저장, 궁합 기능의 자동 테스트가 함께 통과합니다.
- 실제 브라우저에서 입력, 계산 중 상태, 결과 카드와 모바일 레이아웃을 확인합니다.

## 검증 기록

- 2026-09-23: 입력 날짜에서 앞뒤로 60일씩 이동해 같은 일주 후보를 만들고, 같은 기둥·일간·일지·오행 분포를 점수화하는 서버 계산을 구현했습니다.
- 입력 날짜와 네 기둥 또는 세 기둥이 완전히 같은 후보는 결과에서 제외합니다.
- 정상 입력, 시간 미상, 지원 범위 마지막 날, 서버 재계산과 잘못된 입력 거절을 자동 테스트로 확인했습니다.
- 타입 검사와 기존 기능을 포함한 자동 테스트 72개가 통과했습니다.
- 데스크톱 브라우저에서 `2005-12-23 08:37` 입력 후 85점부터 정렬된 결과 카드 5개와 비교 근거를 확인했습니다. 브라우저 오류는 없었습니다.
- 375×812 모바일 화면에서 결과 카드 5개, 버튼 높이 62px, 문서 너비 375px를 확인해 가로 넘침이 없음을 검증했습니다.
