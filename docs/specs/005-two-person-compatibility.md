# 005 두 사람 사주 궁합

## 목적

두 사람이 각각 생년월일과 출생 시각을 입력하고, 사주 원국의 일간·일지·오행 구성을 비교해 관계를 돌아볼 수 있는 궁합 결과를 제공합니다.

## 사용자 흐름

1. `나`와 `상대방`의 양력 생년월일을 각각 입력합니다.
2. 출생 시각을 알면 시간을 입력하고, 모르면 `시간을 잘 모름`을 선택합니다.
3. `두 사람 궁합 보기`를 누릅니다.
4. 궁합 점수, 잘 맞는 점, 부딪힐 수 있는 점, 관계 조언을 한 화면에서 확인합니다.

## 입력 규칙

- 두 사람 모두 생년월일은 필수이며 `1900-01-01`부터 `2026-12-31`까지 지원합니다.
- 출생 시각은 기본적으로 필수입니다.
- `시간을 잘 모름`을 선택한 사람은 시주를 계산·비교에서 제외합니다.
- 시간 미상인 사람이 한 명이라도 있으면 결과에 정확도 안내를 표시합니다.
- 성별, 이름, 관계 유형은 이번 범위에서 받지 않습니다.

## 계산 기준

- 기존 `lib/saju` 계산 결과를 사용하며 AI에게 사주 계산을 맡기지 않습니다.
- 두 사람의 일간 오행 관계, 일지의 합·충 관계, 서로 부족한 오행의 보완 정도를 비교합니다.
- 시간 미상일 때 임의 시각의 시주를 결과에 포함하지 않습니다.
- 점수는 과학적 측정값이 아니라 위 비교 기준을 읽기 쉽게 요약한 참고 지표입니다.
- 결과는 관계를 좋음·나쁨으로 확정하지 않고 강점과 조율할 부분을 함께 설명합니다.

## 화면 상태

1. 두 사람 입력 카드
2. 시간 입력 가능 상태와 `시간을 잘 모름` 선택 상태
3. 입력 오류 안내
4. 궁합 점수와 점수 설명
5. 잘 맞는 점, 부딪힐 수 있는 점, 관계 조언
6. 시간 미상에 따른 정확도 안내

## 제외 범위

- 궁합 결과의 Gemini 해석
- 궁합 결과 저장과 공유
- 결혼·이별 등 중요한 결정을 단정하는 문장
- 음력 입력과 출생 지역에 따른 진태양시 보정

## 완료 조건

- 두 사람의 정상 입력으로 궁합 결과 네 영역이 표시됩니다.
- 각 사람의 `시간을 잘 모름`을 독립적으로 선택할 수 있습니다.
- 시간 미상 선택 시 해당 시간 입력이 비활성화되고 시주는 비교에서 제외됩니다.
- 범위 밖 날짜와 잘못된 시간은 계산하지 않고 이해하기 쉬운 오류를 표시합니다.
- 모바일 화면에서 두 사람 입력과 결과가 가로로 넘치지 않습니다.

## 테스트 계획

- 두 사람 모두 시간을 아는 경우 네 기둥을 사용합니다.
- 한 명 또는 두 명의 시간을 모르는 경우 세 기둥만 사용하고 정확도 안내가 나옵니다.
- 1900년 시작일과 2026년 마지막 날을 허용합니다.
- 1899년과 2027년 날짜를 거절합니다.
- 계산 순서를 바꿔도 같은 점수가 나옵니다.
- 결과에 점수, 잘 맞는 점, 조율할 점, 관계 조언이 모두 존재합니다.
