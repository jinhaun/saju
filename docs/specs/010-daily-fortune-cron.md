# 010 오늘의 운세와 Vercel Cron

## 목적

Google로 로그인한 사용자가 기본 사주에 입력한 생년월일과 출생 시각을 다시 적지 않고, 매일 한국 시간 오전 9시 이후 새로 갱신되는 개인화 오늘의 운세를 확인합니다.

## 이번 기능의 범위

- 로그인 사용자의 가장 최근 기본 사주 입력을 `내 운세 기준 정보`로 저장합니다.
- `/today` 화면에서 오늘의 운세를 확인합니다.
- 한국 시간 오전 9시를 하루의 경계로 사용합니다. 오전 9시 전에는 전날 오전 9시에 열린 운세를 유지합니다.
- Vercel Cron이 매일 `00:00 UTC`(한국 시간 오전 9시)에 보호된 서버 경로를 호출합니다.
- 예약 실행이 늦거나 실패해도 사용자가 `/today`를 열었을 때 해당 날짜 운세가 없으면 한 번 생성합니다.
- 이번 단계에서는 이메일·문자·앱 푸시 알림을 보내지 않습니다.

## 사용자 흐름

1. 사용자가 Google로 로그인합니다.
2. 기본 사주 화면에서 생년월일과 출생 시각 또는 `시간을 잘 모름`을 입력해 해석을 만듭니다.
3. 정상 결과가 저장될 때 같은 입력이 사용자의 `내 운세 기준 정보`로 갱신됩니다.
4. 사용자가 상단의 `오늘의 운세`를 눌러 `/today`로 이동합니다.
5. 오전 9시 기준 오늘 운세가 이미 있으면 저장된 내용을 즉시 봅니다.
6. 아직 없다면 서버가 사주 원국과 오늘의 일주를 계산하고 Gemini로 운세를 생성해 저장한 뒤 보여줍니다.
7. 기준 정보가 없으면 먼저 기본 사주 해석을 한 번 만들라는 안내를 보여줍니다.

## 오늘의 운세 내용

- 오늘을 나타내는 짧은 제목
- 전체 흐름 2~3문장
- `마음과 선택`, `사람과 관계`, `일과 재물` 세 영역
- 오늘 해볼 작은 행동 2개
- 조심해서 볼 점 1개
- 다음 갱신 시각과 참고용 해석 안내

미래나 사건을 확정하지 않고, 의료·법률·투자 결정을 지시하지 않습니다. 특히 재물 내용은 구체적인 상품이나 수익을 예측하지 않습니다.

## 계산과 AI 역할

- `lib/saju`가 저장된 생년월일·출생 시각으로 사주 원국을 계산합니다.
- `lib/saju`가 운세 날짜의 일주를 계산합니다.
- Gemini에는 생년월일·출생 시각 원문을 보내지 않고, 계산된 사주 원국과 오늘 일주만 전달합니다.
- Gemini는 계산값을 바꾸지 않고 쉬운 한국어 운세 문장을 작성합니다.
- 구조화된 JSON 응답을 서버에서 다시 검사하며, 형식이 틀리면 가짜 결과를 저장하지 않습니다.

## 날짜와 예약 실행

- 기준 시간대: `Asia/Seoul`(UTC+9)
- 운세 날짜 변경: 매일 09:00 KST
- Vercel Cron 표현식: `0 0 * * *`(Vercel은 UTC 기준)
- 예약 경로: `/api/cron/daily-fortunes`
- `CRON_SECRET`을 `Authorization: Bearer ...` 헤더와 비교해 예약 경로를 보호합니다.
- Vercel 무료 요금제는 지정된 한 시간 안에서 실행될 수 있어 09:00 정각을 보장하지 않습니다. 이때 `/today`의 사용자 요청 생성이 보완합니다.
- 같은 사용자·같은 운세 날짜는 한 행만 저장해 중복 호출에도 결과가 늘어나지 않게 합니다.

## 데이터와 보안

### `saju_profiles`

- 사용자 ID, 생년월일, 출생 시각 또는 시각 미상 상태, 갱신 시각을 저장합니다.
- 로그인 사용자는 자신의 행만 조회·생성·수정할 수 있습니다.

### `daily_fortunes`

- 사용자 ID, 운세 날짜, 계산된 사주 원국, 오늘 일주, 구조화된 운세, 모델, 생성 시각을 저장합니다.
- 로그인 사용자는 자신의 운세만 조회할 수 있습니다.
- 생성은 사용자 인증을 확인한 서버와 Vercel Cron 서버만 수행합니다.

두 표 모두 공개 스키마의 행 단위 보안(RLS)을 켜고 필요한 권한만 명시합니다. 예약 서버의 `SUPABASE_SECRET_KEY`, Vercel의 `CRON_SECRET`, Gemini 키는 브라우저나 Git에 넣지 않습니다.

## 실패 처리

- 비로그인: Google 로그인이 필요하다는 안내
- 기준 정보 없음: 기본 사주 해석을 한 번 만들라는 안내와 홈 이동 링크
- 환경설정 누락: 관리자 설정이 필요하다는 안내
- Gemini 또는 저장 실패: 기존 운세를 지우지 않고 다시 시도 버튼 제공
- 한 사용자의 생성 실패: Cron 전체를 성공으로 숨기지 않고 실패 수를 서버 기록에 남김

## 완료 조건

- 오전 9시 전후 운세 날짜가 자동 테스트로 검증됩니다.
- 로그인 사용자의 최신 기본 입력이 `saju_profiles`에 저장됩니다.
- 같은 사용자·같은 날짜 운세는 한 번만 저장됩니다.
- `/today`에서 로딩·성공·기준 정보 없음·오류 상태를 확인할 수 있습니다.
- Cron 요청은 올바른 `CRON_SECRET`이 없으면 거절됩니다.
- 타입 검사, 자동 테스트, 프로덕션 빌드가 통과합니다.
- 데이터베이스 마이그레이션 적용과 실제 예약 실행은 각각 별도로 확인합니다.

- 2026-09-28: Gemini Interactions API와 `gemini-3.5-flash-lite`의 구조화된 출력 지원을 확인했습니다.

## 검증 기록

- TypeScript 타입 검사 통과.
- 신규 18개를 포함한 Node 자동 테스트 108개 통과.
- 오전 9시 KST 직전·정각과 월말·연말 날짜 경계, 운세 응답 검사, Gemini 요청의 개인정보 원문 제외를 확인했습니다.
- 오늘의 운세 API의 비로그인 401·기준 정보 없음 404와 Cron 비밀값 미설정 503·불일치 401·정상 200 흐름을 확인했습니다.
- Next.js 프로덕션 빌드 통과. `/today`, `/api/daily-fortune`, `/api/cron/daily-fortunes` 경로가 빌드 결과에 포함됐습니다.
- Supabase RLS 보안 테스트 14개를 추가했습니다. 로컬 Supabase가 실행 중이지 않아 DB 테스트 실행은 연결 거부되었으며, 원격 마이그레이션은 미리 보기만 통과하고 아직 적용하지 않았습니다.
- 로컬 개발 전용 예시 화면을 브라우저에서 열어 데스크톱 배치와 문구를 확인했습니다.
- GitHub 푸시와 Vercel 배포는 수행하지 않았습니다.
