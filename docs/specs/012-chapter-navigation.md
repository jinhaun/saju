# 012 장별 결과 탐색

## 목적

첫 화면에서는 기본 사주와 고민을 한 번만 입력하고, 계산 뒤에는 책의 목차처럼 원하는 장을 골라 한 가지 결과에 집중할 수 있게 합니다.

## 사용자 경험

1. 사용자는 첫 화면에서 생년월일, 출생 시각 또는 `시간을 잘 모름`, 궁금한 주제와 선택 고민을 입력합니다.
2. `나의 사주 해석 보기`를 누르고 기본 입력 검사가 성공하면 입력 화면 대신 장별 목차가 나타납니다.
3. 목차는 다음 다섯 장으로 구성합니다.
   - 제1장 나의 사주 해석
   - 제2장 나와 닮은 사주
   - 제3장 나와 잘 맞는 사주와 오행
   - 제4장 서로의 궁합
   - 제5장 오늘의 운세
4. 장을 누르면 같은 화면에서 선택한 장의 내용만 보여줍니다.
5. 기본 사주 입력값은 `나와 닮은 사주`와 `서로의 궁합`의 `나` 항목에 계속 자동으로 채웁니다.
6. `기본 정보 수정`을 누르면 기존 입력값이 남아 있는 입력 화면으로 돌아갑니다.

## 화면과 접근성

- 현재 선택한 장은 색뿐 아니라 `선택됨` 문구와 보조 기술 상태로 함께 알립니다.
- 목차 버튼은 키보드로 이동하고 실행할 수 있으며 모바일에서도 최소 44px 높이를 유지합니다.
- 장을 바꿔도 이미 입력하거나 계산한 하위 기능의 화면 상태를 가능한 한 유지합니다.
- 좁은 화면에서는 목차 카드가 한 열로 쌓이고 가로 스크롤이 생기지 않아야 합니다.
- 오늘의 운세는 로그인 사용자에게만 실제 결과를 요청하고, 비로그인 사용자에게는 로그인 안내를 보여줍니다.

## 제외 범위

- 주소가 바뀌는 장별 별도 페이지
- 브라우저를 닫은 뒤에도 마지막 장을 기억하는 기능
- 기존 사주 계산, Gemini 해석, 저장, 공유와 궁합 계산 기준 변경
- 새로운 데이터베이스 표 또는 API 추가

## 완료 조건

- 정상 입력 뒤 다섯 장의 목차와 제1장 결과가 표시됩니다.
- 한 번에 입력 화면 또는 선택한 장 하나만 표시됩니다.
- 다른 장으로 이동한 뒤에도 기본 생년월일과 출생 시각 재사용이 유지됩니다.
- 기본 정보 수정 버튼으로 입력 화면에 돌아갈 수 있습니다.
- 현재 장 표시, 키보드 초점, 모바일 한 열 배치를 확인합니다.
- 타입 검사, 자동 테스트, 배포용 빌드와 실제 브라우저 확인을 통과합니다.

## 검증 기록

- 2026-09-28: 기본 입력 성공 뒤 다섯 장의 목차를 열고, 선택한 장 하나만 같은 화면에 표시하도록 구현했습니다.
- 제1장은 Gemini 사주 해석과 원국, 제2장은 닮은 사주, 제3장은 잘 맞는 오행과 관계 조화 공유, 제4장은 두 사람 궁합, 제5장은 오늘의 운세를 연결했습니다.
- 기본 정보 수정 뒤 생년월일·출생 시각·고민 주제가 유지되고, 닮은 사주와 궁합의 `나` 입력에도 같은 값이 채워지는 것을 브라우저에서 확인했습니다.
- 현재 장의 `aria-pressed`와 `선택됨` 문구, 장 이동 뒤 내용 초점, 비로그인 오늘 운세 안내를 자동 테스트로 확인했습니다.
- 375×812 모바일 화면에서 목차가 한 열로 쌓이고 카드 높이가 145~172px이며, 문서 가로 너비가 화면 너비를 넘지 않는 것을 확인했습니다.
- 812×375 가로 화면에서도 문서 너비가 화면 너비를 넘지 않고 현재 장 표시가 유지되는 것을 확인했습니다.
- 신규 7개를 포함한 전체 자동 테스트 126개, TypeScript 타입 검사와 Next.js 배포용 빌드가 모두 통과했습니다.
