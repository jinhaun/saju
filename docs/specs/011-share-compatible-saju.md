# 011 관계의 조화 결과 공유

## 목적

사용자가 `나와 잘 맞는 사주` 결과를 잘 맞는 오행의 사람에게 부담 없이 전달할 수 있도록, 전체 사주 결과가 아닌 `관계의 조화 살펴보기` 내용만 한 장의 이미지로 저장하거나 공유합니다.

## 사용자 경험

1. 기본 사주를 계산하면 `관계의 조화 살펴보기` 영역이 나타납니다.
2. `잘 맞는 오행` 옆의 `공유하기` 버튼을 누릅니다.
3. 파일 공유를 지원하는 휴대전화에서는 기기의 공유 창이 열립니다.
4. 공유 창을 지원하지 않는 브라우저에서는 같은 내용이 PNG 이미지로 저장됩니다.
5. 처리 중, 저장 완료, 공유 취소와 실패 상태를 버튼 아래에서 확인합니다.

## 저장 이미지 내용

- `관계의 조화 살펴보기` 제목과 `나와 잘 맞는 사주` 제목
- 잘 맞는 오행 세 가지
- 세 추천 카드의 이름, 일간과 설명
- 일지 육합 설명과 참고 안내
- 서비스 이름 `나의 사주 안내서`

## 개인정보와 제외 범위

- 생년월일, 출생 시각, 고민, Gemini 해석과 전체 사주 기둥은 이미지에 넣지 않습니다.
- 서버에 새 파일을 저장하거나 외부 서비스로 자동 전송하지 않습니다.
- 사용자가 기기의 공유 대상을 고르기 전에는 어느 곳에도 전송하지 않습니다.
- 추천 계산 기준과 기존 결과 저장 형식은 바꾸지 않습니다.

## 화면 기준

- `공유하기` 버튼은 `잘 맞는 오행`과 같은 요약 줄에 배치합니다.
- 버튼은 키보드로 사용할 수 있고 모바일에서 최소 44px 높이를 유지합니다.
- 처리 중에는 중복 실행을 막고 `이미지 준비 중...`을 표시합니다.
- 완료·취소·실패 안내는 보조 기술이 읽을 수 있는 상태 영역으로 제공합니다.
- 좁은 화면에서는 오행 문구와 버튼이 자연스럽게 줄바꿈됩니다.

## 완료 조건

- 저장 이미지에 관계의 조화 내용만 포함됩니다.
- 공유 지원 환경에서는 PNG 파일 공유 창이 열립니다.
- 미지원 환경에서는 PNG 파일이 저장됩니다.
- 이미지 생성 실패 시 사용자가 다시 시도할 수 있는 안내가 표시됩니다.
- 타입 검사, 자동 테스트와 실제 브라우저 확인을 통과합니다.

## 검증 기록

- 공유용 SVG와 PNG 생성, 기기 공유 창 및 미지원 환경의 파일 저장 처리를 구현했습니다.
- 이미지에는 관계 조화 제목, 토·수·목 추천, 세 추천 카드와 진(辰)–유(酉) 육합만 포함하고 생년월일·시각·고민·Gemini 해석은 제외했습니다.
- 전용 자동 테스트 3개와 기존 기능을 포함한 전체 자동 테스트 119개가 통과했습니다.
- 타입 검사와 Next.js 배포용 빌드가 통과했습니다.
- 실제 브라우저에서 `공유하기` 버튼, 처리 중 상태와 `관계의 조화 이미지를 공유했습니다.` 완료 안내를 확인했습니다.
- 375×812 모바일 화면에서 버튼 높이 44px, 가로 넘침 없음과 한 열 카드 배치를 확인했습니다.
