# 009 나와 잘 맞는 사주 특징

## 목적

사용자가 기본 사주 해석을 본 직후, 자신의 일간 오행과 일지를 기준으로 어떤 사주 특징과 조화를 이루기 쉬운지 다시 입력하지 않고 확인할 수 있게 합니다.

## 사용자 경험

1. 사용자가 기본 사주 정보를 입력하고 `나의 사주 해석 보기`를 누릅니다.
2. 기본 계산이 끝나면 같은 결과 카드 안에 `나와 잘 맞는 사주` 영역이 나타납니다.
3. 사용자는 자신을 북돋는 기운, 자신의 기운이 자연스럽게 이어지는 기운, 부족한 부분을 보완하는 기운을 확인합니다.
4. 카드 목록 위에서 `잘 맞는 오행` 세 가지를 한눈에 확인합니다.
5. 일지의 합 관계가 있는 글자도 함께 확인합니다.

## 계산 기준

- 기존 `lib/saju`가 계산한 일간 오행, 일지와 오행 분포만 사용합니다.
- 오행의 상생 순서는 `목 → 화 → 토 → 금 → 수 → 목`을 사용합니다.
- 추천 특징은 다음 세 가지를 중복 없이 보여줍니다.
  1. 사용자의 중심 기운을 생하는 오행
  2. 사용자의 중심 기운이 생하는 오행
  3. 사용자의 사주에서 상대적으로 적고 앞의 두 오행과 겹치지 않는 보완 오행
- 일지는 기존 궁합 계산과 같은 육합 관계를 사용합니다.
- Gemini에게 계산을 맡기거나 추가 API를 호출하지 않습니다.

## 화면과 문구

- 결과 영역 안에서 오행 분포보다 먼저 보여줍니다.
- 카드 목록 위에 `잘 맞는 오행`과 추천 오행 세 개를 한 줄로 함께 표시합니다.
- 각 추천 카드에 오행 이름, 해당 일간의 한글 이름 두 개와 잘 맞는 이유를 표시합니다.
- 점수나 절대적인 `최고의 궁합` 표현을 사용하지 않습니다.
- 실제 두 사람의 전체 궁합은 상대방의 사주까지 비교해야 한다는 안내를 표시합니다.
- 모바일에서는 추천 카드가 한 열로 쌓이고 가로 스크롤이 생기지 않아야 합니다.

## 제외 범위

- 특정 생년월일이나 실제 이용자 추천
- 연예인·유명인 추천
- 상대방 없이 궁합 점수 산출
- Gemini 추가 해석
- 결과 저장 형식 변경

## 완료 조건

- 유효한 기본 사주 계산 뒤 추천 특징 세 개와 조화 일지가 표시됩니다.
- 추천 오행 세 개는 중복되지 않습니다.
- 일간 오행 다섯 종류에서 상생 관계가 올바르게 계산됩니다.
- 기존 사주 해석, 저장, 비슷한 사주와 두 사람 궁합 기능이 영향을 받지 않습니다.
- 타입 검사, 관련 자동 테스트와 실제 브라우저 확인을 통과합니다.

## 검증 기록

- `lib/saju/compatible-profile.ts`에 일간 오행의 상생 방향, 오행 분포의 보완 기운과 일지 육합 계산을 구현했습니다.
- 기본 결과 카드에 추천 특징 세 개와 육합 일지, 실제 두 사람의 전체 사주를 함께 봐야 한다는 안내를 추가했습니다.
- 목·화·토·금·수 다섯 일간의 상생 관계, 추천 중복 방지, 열두 일지의 양방향 육합, 보완 오행 선택과 일간 이름을 자동 테스트 9개로 확인했습니다.
- 타입 검사와 기존 기능을 포함한 전체 자동 테스트 89개가 통과했습니다.
- 브라우저에서 `1990-01-15 12:30`을 계산해 금 일간에 대한 토·수·목 추천과 진(辰)–유(酉) 육합이 표시되는 것을 확인했습니다.
- 375×812 모바일 화면에서 추천 카드 세 개가 한 열로 쌓이고 가로 잘림이 없는 것을 확인했습니다.
- 실제 화면 시험 중 Gemini 해석 요청은 실패했지만, 새 영역은 기본 계산만 사용하므로 그대로 정상 표시되는 것을 확인했습니다.
- 카드 위에 추천 순서와 같은 `잘 맞는 오행: 토 · 수 · 목` 요약을 추가하고, 알려진 입력 회귀 테스트와 전체 자동 테스트 90개를 통과했습니다.
- 브라우저에서 `1990-01-15 12:30` 결과의 요약과 세 추천 카드가 같은 토·수·목 순서로 표시되는 것을 확인했습니다.
