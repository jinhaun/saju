# 006 조선 고서 시각 디자인

## 목적

기존 사주·궁합·로그인·결과 저장 기능은 유지하면서, 조선시대 서책과 궁중 의궤를 참고한 차분하고 신뢰감 있는 화면으로 바꿉니다.

## 선택한 방향

- 기본 구조는 한지, 먹색 글자, 쪽빛 표지와 실 제본을 연상시키는 `선비의 서책` 시안을 사용합니다.
- 강조 색과 주요 버튼에는 `궁중 의궤`의 짙은 녹색과 절제된 금색 테두리를 섞습니다.
- 역사적 분위기는 색·선·종이 질감으로 표현하고, 본문은 현대 한글 가로쓰기와 익숙한 입력 형식을 유지합니다.

## 화면 규칙

- 배경은 낮은 대비의 한지 질감으로 표현해 글자 읽기를 방해하지 않습니다.
- 큰 제목은 명조 계열, 본문과 입력 항목은 가독성이 높은 고딕 계열을 사용합니다.
- 입력 카드 왼쪽에는 쪽빛 책등과 제본점을 장식으로 표현합니다.
- 주요 행동 버튼은 짙은 녹색, 얇은 금색 테두리로 표시합니다.
- 선택 상태는 녹색 배경과 붉은 인장색을 함께 사용해 색 하나에만 의존하지 않습니다.
- 클릭 요소는 최소 44px 높이, 키보드 초점 표시와 모바일 한 열 배치를 유지합니다.
- 장식 때문에 레이아웃이 움직이지 않으며, 애니메이션 감소 설정을 존중합니다.

## 시안 충실도 보완 (2차)

첫 적용본은 색과 질감 위주여서 기준 시안보다 간소하게 보였습니다. 2차 적용에서는 아래 요소를 화면의 중심 구조로 사용합니다.

- 첫 화면 전체를 한 권의 펼친 서책처럼 보이게 하고, 왼쪽 쪽빛 책등과 네 군데 실 제본을 크게 드러냅니다.
- 제목 영역 오른쪽 절반에는 수묵 산수, 소나무, 붉은 해가 있는 전용 배경 그림을 배치합니다.
- 입력 영역은 서책 안쪽의 별도 장지처럼 겹 테두리와 금빛 모서리 장식을 사용합니다.
- 데스크톱의 고민 선택 항목은 3열로 넓게 배치하고, 모바일에서는 1열로 바꿉니다.
- 장식은 풍부하게 하되 입력 글자와 버튼의 대비, 키보드 초점, 최소 44px 조작 크기는 그대로 유지합니다.
- 전통 분위기를 결정하는 큰 제목·중간 제목·항목명·주요 버튼에는 `Song Myung` 웹폰트를 사용하고, 긴 본문과 입력값에는 기존 가독성 글꼴을 유지합니다.
