# 008 사주 입력 재사용

## 목적

사용자가 기본 사주 해석을 위해 입력한 생년월일과 출생 시각을 아래의 `나와 닮은 사주`와 `서로의 궁합`에 다시 입력하지 않도록 자동으로 채웁니다.

## 사용자 경험

1. 사용자가 기본 사주 화면에 생년월일, 출생 시각 또는 `시간을 잘 모름`, 고민 주제를 입력합니다.
2. `나의 사주 해석 보기`를 누르고 기본 입력 검사가 성공하면 같은 생년월일과 시간 상태를 아래 기능에 전달합니다.
3. `나와 닮은 사주`의 생년월일·출생 시각·시간 미상 상태를 채웁니다.
4. `서로의 궁합`에서는 `나`의 생년월일·출생 시각·시간 미상 상태만 채우고 `상대방` 입력은 변경하지 않습니다.
5. 사용자는 자동으로 채워진 값을 각 화면에서 다시 수정할 수 있습니다.

## 범위와 제외

- 입력 전달은 현재 열린 페이지의 React 상태에서만 처리하고 브라우저 저장소나 데이터베이스에는 추가 저장하지 않습니다.
- 비슷한 사주 계산과 궁합 계산 버튼은 자동으로 누르지 않습니다.
- 고민 주제와 자유 고민은 다른 두 기능에 전달하지 않습니다.
- 기본 사주 입력이 유효하지 않으면 아래 입력을 변경하지 않습니다.

## 완료 조건

- 정상 기본 입력 제출 후 두 하위 기능에 같은 생년월일이 표시됩니다.
- 출생 시각을 아는 경우 같은 시간이 표시됩니다.
- `시간을 잘 모름`이면 두 하위 기능의 해당 버튼이 선택되고 시간 입력이 비활성화됩니다.
- 궁합의 상대방 입력은 유지됩니다.
- 자동 입력 뒤 사용자가 값을 수정할 수 있습니다.
- 타입 검사와 관련 자동 테스트가 통과하고 실제 브라우저에서 동작을 확인합니다.

## 검증 기록

- `lib/saju/reused-birth-input.ts`에서 입력값을 재사용하기 위한 형식으로 정리하도록 구현했습니다.
- 기본 사주 입력을 공유하는 화면 상태를 추가하고, 비슷한 사주와 궁합의 ‘나’ 입력란이 이를 받아 자동으로 채워지도록 연결했습니다.
- 출생 시각을 모르는 경우에는 시간 값을 비우고 ‘시간을 잘 모름’ 상태가 함께 전달되는지 자동 테스트로 확인했습니다.
- 브라우저에서 `2001-02-03`, `04:05`를 입력해 기본 해석 버튼을 누른 뒤 비슷한 사주와 궁합의 ‘나’ 항목에 같은 값이 채워지고, ‘상대방’ 항목은 비어 있는 것을 확인했습니다.
- 타입 검사에 통과했고 전체 자동 테스트 80개가 모두 통과했습니다.
