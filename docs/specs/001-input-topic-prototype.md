# 001 입력·고민 선택 프로토타입

## 목적

사주를 처음 접하는 사용자가 생년월일과 출생 시각뿐 아니라 지금 궁금한 고민을 함께 입력하고, 기본 계산 결과와 자신이 고른 고민을 한 화면에서 확인합니다.

## 범위

- 양력 생년월일과 출생 시각 입력 또는 `시간을 잘 모름` 선택
- 고민 주제 한 가지 선택
  - 연애·관계
  - 진로·직업
  - 재물·돈
  - 인간관계
  - 성격·강점
  - 올해의 흐름
- 선택 사항인 자유 고민 입력(최대 200자)
- 기존 사주 원국 계산 결과 표시
- 선택한 고민과 자유 고민 재표시
- 모바일과 키보드 사용자를 고려한 반응형 입력 화면

## 제외 범위

- 개인화 해석 문장 생성
- AI API 호출
- 회원가입, 로그인, 결과 저장, 결제
- 궁합, 추가 질문, 알림

## 동작 요구사항

1. 사용자는 날짜와 고민 주제를 입력하고, 출생 시각을 알면 시각을 입력하거나 모르면 `시간을 잘 모름`을 선택합니다.
2. 고민 주제는 카드형 라디오 버튼으로 한 가지만 선택합니다.
3. 자유 고민은 선택 사항이며 200자 이내로 입력합니다.
4. 입력값은 기존 `validateInput`을 거쳐 계산합니다.
5. 성공하면 선택 주제, 자유 고민, 일주, 일간과 세 기둥 또는 네 기둥을 표시합니다.
6. `시간을 잘 모름`을 선택하면 시간 입력을 비활성화하고 정오 기준으로 년주·월주·일주만 계산하며 정확도 안내를 표시합니다.
7. 해석 영역에는 아직 해석 기능이 포함되지 않았음을 안내합니다.
8. 실패하면 결과를 지우고 오류 문장을 화면 읽기 프로그램에도 전달합니다.

## 검증 계획

- 기존 공개 기준 사례의 사주 계산값이 바뀌지 않는지 확인합니다.
- 새 고민 주제 여섯 가지가 입력 검사에서 허용되는지 확인합니다.
- 200자를 넘는 자유 고민과 필수값 누락을 거부하는지 확인합니다.
- 브라우저에서 입력→계산→결과 표시 흐름을 확인합니다.
- 375px 안팎의 모바일 화면과 넓은 화면에서 가로 스크롤이나 잘림이 없는지 확인합니다.
