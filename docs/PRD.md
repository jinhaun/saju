# 📋 기획서 (PRD) : 나의 사주 안내서

> 사주를 처음 접하는 사람도 자신의 고민을 먼저 고르고, 어려운 용어에 막히지 않도록 돕는 모바일 우선 웹 서비스입니다.

작성일: 2026-09-23  
작성자: 수업 참가자

---

## 1. 풀고자 하는 문제

- **지금은 이렇게 해요:** 기존 사주 서비스에서 생년월일과 출생 시각을 입력하고 일반적인 결과를 읽습니다.
- **이게 불편해요:** 결과가 누구에게나 비슷하고, 사용자가 가진 연애·진로·재물 같은 실제 고민과 연결되지 않습니다. 한자와 전문 용어가 많아 초보자가 핵심을 이해하기도 어렵습니다.
- **이렇게 되면 좋겠어요:** 먼저 고민을 고른 뒤 쉬운 말로 된 핵심 요약을 보고, 필요하면 자세한 해석까지 이어서 읽을 수 있으면 좋겠습니다.

## 2. 사용자

- **누가 쓰나요?** 사주를 처음 접하는 사람, 연애·직업 등 구체적인 고민이 있는 사람, 본인과 주변 사람의 사주를 가볍게 확인하려는 사람
- **언제 쓰나요?** 고민을 정리하거나 자신을 돌아보고 싶을 때
- **어디서 쓰나요?** 휴대전화 또는 컴퓨터의 웹 브라우저

## 3. 입력 자료

- **입력 내용:** 양력 생년월일, 출생 시각 또는 `시간을 잘 모름`, 고민 주제, 선택 사항인 자유 고민
- **고민 주제:** 연애·관계, 진로·직업, 재물·돈, 인간관계, 성격·강점, 올해의 흐름
- **반드시 필요한 항목:** 생년월일, 고민 주제 한 가지. 출생 시각은 알 때만 입력합니다.
- **개인정보 포함 여부:** 생년월일과 출생 시각을 사용합니다. Gemini에는 원문 대신 서버에서 계산한 사주 값과 고민만 전달합니다. 로그인한 사용자의 완성된 결과는 본인만 다시 볼 수 있도록 Supabase에 저장합니다.
- **현재 제한:** 양력과 1900년 1월 1일부터 2026년 12월 31일까지의 날짜를 지원합니다. 출생 시각을 모르면 정오를 기준으로 년주·월주·일주를 계산하고 시주는 제외하므로 절기 경계에서는 결과가 달라질 수 있습니다.

## 4. 핵심 기능 (MVP)

1. 생년월일과 출생 시각을 입력하거나 `시간을 잘 모름`을 선택할 수 있습니다.
2. 여섯 가지 고민 주제 중 하나를 선택하고 자유 고민을 최대 200자까지 적을 수 있습니다.
3. 기존 `lib/saju` 계산기로 년주·월주·일주·시주와 일간을 계산합니다. 시각을 모르면 시주는 제외합니다.
4. 계산 결과와 사용자가 고른 고민을 한 화면에서 확인할 수 있습니다.
5. 잘못되거나 빠진 입력에는 이해하기 쉬운 오류 문장을 보여줍니다.
6. Gemini가 계산 결과와 고민을 바탕으로 핵심 요약과 자세한 해석을 작성합니다.
7. Google로 로그인한 사용자의 정상 해석을 자동 저장하고, 본인의 이전 결과만 다시 보거나 삭제할 수 있습니다.
7. 두 사람의 생년월일과 출생 시각을 비교해 궁합 점수, 잘 맞는 점, 조율할 점과 관계 조언을 보여줍니다. 출생 시각을 모르면 시주를 제외합니다.
8. 1900년부터 2026년까지의 달력에서 일주가 같고 다른 기둥과 오행 구성이 비슷한 사주를 찾아줍니다.

- **프로그램이 할 것:** 입력 검사, 사주 원국 계산, 고민 정보와 계산 결과 표시, Gemini 해석 요청과 응답 구조 검사
- **Gemini에게 맡길 것:** 계산된 사주 값과 고민을 쉬운 한국어 해석으로 설명
- **사람이 확인할 것:** 입력 내용, 해석이 실제 상황에 맞는지, 중요한 결정에 참고할 다른 정보

## 5. 결과와 완료 조건

- **결과물과 위치:** Next.js 웹 프로토타입 `day09/`
- **정상 입력:** 유효한 생년월일·고민 주제와 출생 시각 또는 `시간을 잘 모름`을 입력하면 선택한 고민, 일주, 일간, 사주 세 기둥 또는 네 기둥이 화면에 나타납니다.
- **선택 입력:** 자유 고민을 적으면 결과 화면에서 입력한 고민을 다시 확인할 수 있습니다.
- **누락 또는 실패:** 필수 항목이 비어 있거나 지원 범위를 벗어나면 해당 내용을 고칠 수 있는 오류 문장이 보입니다.
- **해석 영역:** 핵심 요약을 먼저 보여주고, 기질과 강점·선택한 고민·주의해서 볼 점·행동 제안 순서로 표시합니다.
- **저장:** 비로그인 결과는 저장하지 않습니다. 로그인한 사용자의 정상 해석만 Supabase에 저장하며, 사용자별 접근 규칙으로 본인의 결과만 조회·삭제할 수 있습니다.
- **해석 실패:** 기본 계산 결과는 유지하고 실패 원인에 맞는 안내와 다시 시도 버튼을 보여줍니다.
- **비슷한 사주:** 실제 이용자 정보 없이 달력 날짜를 비교해 닮은 정도가 높은 후보 5개와 그 이유를 보여줍니다.

## 9. 첫 구현 목표 (30분 예산)

고민 주제 카드와 자유 입력란을 기존 입력 화면에 추가하고, 계산 후 선택한 고민과 사주 네 기둥을 결과 카드에서 확인할 수 있게 합니다. 해석 문장은 생성하지 않습니다.

## 10. 테스트 사례

|---|---|---|---|
| 1 | 정상 날짜·시각과 `진로·직업`, 자유 고민 입력 | 선택한 고민과 계산된 일주·일간·네 기둥이 표시됨 | 보통 |
| 2 | 출생 시각 없이 `시간을 잘 모름` 선택 | 시주를 제외한 세 기둥과 정확도 안내가 표시됨 | 보통 |
